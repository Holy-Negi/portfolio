電子実験ノート（ELN）

個人開発 / 2026〜

化学反応の記録・管理を目的とした電子実験ノート（ELN; Electronic Lab Notebook）です。SMILES 記法で化合物を入力するだけで、RDKit が自動計算した分子量・LogP・InChIKey などの物性値を PostgreSQL に保存し、FastAPI 経由で React フロントエンドに表示する、という一連のパイプラインを備えています。

ケモインフォマティクスとインフラ設計の実践的な習得を目的として、データベース設計・API 実装・化学計算までを一通り自作しています。

Python FastAPI PostgreSQL React RDKit
github.com/Holy-Negi/synth-eln

05 Activities

課外活動

学業・研究以外に継続して取り組んできた活動です。

北海道大学生活協同組合 学生組織委員会 HPはこちら

2022年4月〜

大学生協には、組合員のよりよい生活を目指して活動を行う「組織委員会」という組織が存在し、私はそのうちの1つである学生組織委員会に大学入学時に所属しました。 学生委員会ではさまざまな活動を経験しましたが、中でも力を入れたのは「共済活動」です。 共済活動は、学生のための保障制度である「学生総合共済」の加入や認知を広げるための活動です。 自転車の無料点検を行う自転車点検会や、防災意識の向上を目的とした防災企画などの立案・運営を行いました。

大学生協北海道ブロック 学生事務局 HPはこちら

2024年5月〜

大学生協北海道ブロックは、北海道にある大学生協の組織活動を管轄する組織で、学生事務局はその中でも特に学生組織委員会を取りまとめる組織です。 学生組織委員会の引退後、そのまま学生事務局に所属しました。 学生事務局では、全道の学生委員が学生総合共済や共済活動について学べるようなセミナーの企画・運営を主に行いました。

北海道大学生活協同組合 院生組織委員会 HPはこちら

2026年4月〜

院生組織委員会は、主に大学院生の生活をより良くすることを目的とした組織委員会です。 北海道ブロック学生事務局の引退後、そのまま院生委員会に所属しました。 これまでほど活動はできていませんが、主に院生どうしの交流を目的とした院生交流会の企画を行っています。
