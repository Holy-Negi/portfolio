02 Projects

電子実験ノート（ELN）

個人開発 / 2026〜

化学反応の記録・管理のための電子実験ノート（ELN: Electronic Lab Notebook）です。化合物を SMILES 記法で入力すると、RDKit が分子量・LogP・InChIKey などの物性値を自動で計算し、PostgreSQL に保存します。保存したデータは FastAPI を通じて React の画面に表示されます。

ケモインフォマティクスとWebアプリ開発を実践で身につけるため、データベース設計から API の実装、化学計算、フロントエンドまでをすべて自作しています。

Python FastAPI PostgreSQL React RDKit
github.com/Holy-Negi/synth-eln

05 Activities

課外活動

学業・研究と並行して、学部1年から続けている大学生協での活動です。

北海道大学生活協同組合 学生組織委員会 公式サイト

2022年4月〜

大学生協には、組合員の暮らしをよくするための活動を担う「組織委員会」があり、入学と同時にその一つである学生組織委員会に加わりました。特に力を入れたのは、学生向けの保障制度「学生総合共済」を広めるための共済活動です。自転車の無料点検会や、防災意識を高めるための企画を立案・運営しました。

大学生協北海道ブロック 学生事務局 公式サイト

2024年5月〜

北海道ブロックは道内の大学生協の組織活動をまとめる組織で、学生事務局は各大学の学生組織委員会を取りまとめる役割を担っています。学生組織委員会を引退した後に所属し、全道の学生委員が学生総合共済と共済活動について学ぶセミナーを中心に、企画・運営を担当しました。

北海道大学生活協同組合 院生組織委員会 公式サイト

2026年4月〜

大学院生の暮らしをよくすることを目的とした組織委員会です。学生事務局を引退した後に所属し、現在は院生どうしの交流会を企画しています。
